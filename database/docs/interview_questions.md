# EduNexus Previous Campus Interview Questions Bank

## Data Structures & Algorithms (DSA)
- Given a binary tree, print its zigzag level order traversal.
- Implement an LRU Cache with O(1) time complexity for get and put operations.
- Find the longest palindromic substring in a given string.
- Detect and remove loop in a linked list.

## System Design & CS Fundamentals
- Design a scalable URL shortener service (like Bitly).
- Explain ACID properties in DBMS and compare SQL vs NoSQL.
- Explain TCP 3-way handshake and HTTP vs HTTPS protocol differences.
- What are virtual memory, paging, and thrashing in Operating Systems?

## Behavioral & HR Questions
- Tell me about a challenging project you worked on and how you resolved team conflicts.
- Why do you want to join our company?
- Where do you see yourself in 3 years?
